# SEMBOLLER

| Sembol | Açıklama |
|--------|---------|
| d(x, y) | İki vektör arasındaki cosine uzaklığı |
| e | Gömme vektörü (embedding vector), ℝ⁷⁶⁸ |
| e_s | Sinyal vektörü, ℝ⁸ |
| e_f | Birleşik öznitelik vektörü, ℝ⁷⁷⁶ |
| p_f | Sahte haber (FAKE) sınıf olasılığı, [0, 1] |
| r | NLP kural tabanlı risk skoru, [0, 1] |
| c | Ağırlıklı topluluk kararı (combined score), [0, 1] |
| w_m | Model ağırlığı (0,70) |
| w_r | Kural ağırlığı (0,30) |
| θ | Cosine benzerlik eşiği (0,08) |
| n | Örnek sayısı |
| k | En yakın komşu sayısı (k = 3) |
